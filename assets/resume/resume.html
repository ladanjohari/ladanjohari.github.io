Selected Work

Session Indicator — AI Agent Interface, macOS
2026 · Case Study
SwiftUI · Interaction Design · State-Machine Design · Motion Design · Working macOS App

Designed and built a macOS menu-bar app that restores awareness when multiple AI agents run in parallel, without breaking focus. Defined a five-state session model where motion signals state and color signals exception, with full Reduce Motion accessibility and Apple HIG conventions throughout. Engineered the SwiftUI app end to end: live detection of running agent sessions, state read from session transcripts, all five states shipped and in daily use on my own machine.

Prompted Find — Semantic Video Navigation
2025 · Case Study
Interaction Design · Semantic Decomposition · Coded Prototype (HTML/JS) · Design Systems

Designed a new interaction pattern for long-form video: ask a question in natural language, get a timestamp you can trust. Built the working prototype on a 74-minute lecture, decomposing the timeline into labeled semantic segments, and architected the understanding layer so real embeddings drop in without changing the interaction.

2024 · Case Study
