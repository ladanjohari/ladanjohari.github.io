AI Interaction Pattern · Prototype · Semantic Navigation

PromptedFind

A prototype for prompt-based navigation inside media — ask for a moment in plain language, and jump straight to it.

2025 / HTML · CSS · JavaScript / GitHub →

The Gap

“What if ‘Ask’ did more than answer questions — what if it became a navigation layer?”

In the prototype, a user can ask for a moment in a video using natural language, receive interpreted results as meaningful time ranges, and click those ranges to jump directly to the relevant part of the content.

The design focus wasn’t building a full AI system — it was making the interaction believable: a YouTube-like watch page, an Ask panel that feels native to the surface, and AI-style summaries instead of raw transcript snippets.

Three Decisions

The prototype is built around three choices that turn a question-answering pattern into a navigation primitive.

01

Ranges, not points

“Understanding has duration.”

A semantic timeline maps ideas to time ranges rather than single timestamps, mirroring how a moment in a video actually unfolds.

Rejected: Single-timestamp jump links are precise but lose the surrounding context that makes a moment legible.

02

Summaries, not transcripts

“Read the idea, not the captions.”

Results are shown as AI-style summaries instead of raw transcript snippets — closer to how a person would describe what happens.

Rejected: Raw transcript excerpts are accurate but read like search results, not answers.

03

Native to the watch page

“The Ask panel belongs here.”

Built into a YouTube-like watch page so the Ask panel and semantic timeline feel like part of the player, not a bolted-on chat widget.

Rejected: A separate chat overlay would decouple the answer from the content it describes.

The broader idea: this pattern isn’t limited to video. The same navigation model can extend to podcasts, PDFs, lectures, and document viewers by swapping the host adapter while keeping the interaction intact — understanding as a first-class interface primitive.
