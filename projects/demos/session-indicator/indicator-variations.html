Indicator Variations

Eight visual languages for the same underlying data. Each card shows the variation in context and a legend of all five states.

recommended

Pulse

Shimmer for active, amber for waiting. Motion and color each carry one independent signal.

states

idle
active
waiting
error
done
+Apple HIG native, fits system UI
+Motion and color are independent channels
–Color language needs one-time learning

Pixel Heart

Same state logic as Pulse, but dots are replaced with pixel art hearts.

states

+Charming and completely unexpected
+Identical state logic — no relearning
–Playful tone, not for Apple OS proposal

Pixel Art

Each state is a distinct pixel icon. Fire, ice, bolt, star, skull. No legend required.

states

+Icons are self-describing, no legend
+Gaming and developer culture native
–Wider pill, too expressive for all-day use

Pixel Flame

Each session is a flame. Flame height maps directly to workload.

states

idle
active
waiting
error
done
+Nothing in any menu bar looks like this
+Flame height intuitively maps to activity
–Too playful for Apple OS proposal

Waveform

Bars bounce with activity. A still bar means waiting or done.

states

idle
active
waiting
error
done
+Audio and CPU meter familiarity
+Activity rate readable without learning
–Bars hard to read at peripheral distance

Agent Meter

Segmented LED bars load bottom to top. Green at base, orange at peak.

states

idle
active
waiting
error
done
+Segment fill shows task progress clearly
+Classic LED VU meter, hardware familiar
–Taller than standard menu bar items

Orbital

Spinning arc per session. Spin speed directly encodes activity rate.

states

idle
active
waiting
error
done
+Spin speed maps directly to activity rate
+Full circle completing = done is natural
–Spinning motion distracting over a full day

Claude Native

Warm coral palette. Feels like a first-party Anthropic product.
