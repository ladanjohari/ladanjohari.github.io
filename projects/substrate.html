Hand a goal to AI agents. It comes back as a plan with checks. You approve it, agents work it, and nothing closes until the proof is written down.

The real panel and the real window, both rendered from a live record. Click a step.

Why it matters

When agents work on their own, it is hard to tell what they did and what is waiting on you.

The plan sits in a chat history. An agent decides for itself when it is finished. When one needs a decision, nothing tells you.

It’s for people who run agents: engineers running several at once, and anyone who has to stand behind what the agents produced.

The idea

Two rules, kept by the record itself. Nothing runs until a person approves the plan. Nothing closes until each of its checks has evidence. Everything else in the product follows from those two.

Most agent tools trust the agent to say it is done. Here the record refuses to close a task until the proof is written down.

That takes two surfaces. The menu bar is for attention: one goal at a time, what needs you, and nothing else. The window is for structure: every goal, the tasks it broke into, what each one waits on, and the checks that close it.

Where else it works

Any work an agent does for you: code, research, writing. The gate stays the same.

What’s next

  • One Swift app. The rules already run in Swift and match the original answer for answer, so it can ship as a single download.
  • A signed release. So it opens like any other Mac app, without a warning.
  • Agents in Claude Code. The plugin already installs, so agents can work against the same record from any session.
