Why it matters

When agents work on their own, it is hard to tell what they did and what is waiting on you.

The plan sits in a chat history. An agent decides for itself when it is finished. When one needs a decision, nothing tells you.

It’s for people who run agents: engineers running several at once, and anyone who has to stand behind what the agents produced.

The idea

Two rules, kept by the record itself. Nothing runs until a person approves the plan. Nothing closes until each of its checks has evidence. Everything else in the product follows from those two.

Most agent tools trust the agent to say it is done. Here the record refuses to close a task until the proof is written down.

That takes two surfaces. The menu bar is for attention: one goal at a time, what needs you, and nothing else. The window is for structure: every goal, the tasks it broke into, what each one waits on, and the checks that close it.

What I decided, and what it cost

The menu bar, not a window. Supervision is something you do between other things, so it had to be somewhere you already look, not an app you remember to open. What it cost: 368 points is no place for a task tree, so the structure needed a second surface, and I had to decide what belongs in each.

The record refuses, rather than the interface warning. A task cannot reach done while a check is open, and a check cannot be met without evidence. The rules live in the store, so the app and the command line cannot disagree about what is allowed. What it cost: you cannot close something by insisting. You write what makes it true, which is slower, and is the point.

Python first, then Swift. The store and the command line were quicker to think in Python, but a Mac app should ship as one download. What it cost: two implementations at once. They are kept honest by a comparison that runs both against a single record and fails if they answer differently.

The gate does not care what the work is. Code, research, writing: an agent does it, and the same two rules decide when it is finished.

What’s next

  • One Swift app. The rules already run in Swift and match the original answer for answer, so it can ship as a single download.
  • A signed release. So it opens like any other Mac app, without a warning.
  • Agents in Claude Code. The plugin already installs, so agents can work against the same record from any session.

Try it

It runs on macOS 14 or newer. Two steps, and the second one is a double click. 

git clone https://github.com/ladanjohari/substrate.git
cd substrate && open "Open Substrate.command"

The build is not signed yet, so the first open asks whether you meant it. Right click the file, choose Open, then Open again.
