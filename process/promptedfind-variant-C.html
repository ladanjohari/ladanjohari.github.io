Prompted Find

Ask a question about a video. Jump to the exact moment that answers it.

2025 / Coded prototype · HTML/JS / GitHub →

Video is easy to watch and hard to search

A document has headings; a video only has time. Prompted Find makes the timeline navigable by meaning: ask what you want to find, and the answer is a timestamp you can trust, not a transcript.

“Search as navigation.”

The Interaction

Three steps, none of them leave the video

Open the Ask panel and the timeline decomposes into labeled segments. Ask, or point at a segment, and relevant ranges highlight. Click, and you land in the moment with the summary still beside you.

“Context persists.”

How It Works

Ask
A natural-language question. “How do they slow down?”
Expand
Concept aliases broaden the query. “EDL” also means entry, descent, landing.
Score
Every segment’s label and summary is scored against the expanded terms.
Locate
Matching ranges highlight on the timeline. Clicking one seeks the video.

Semantic Decomposition, applied to a 74-minute NASA talk

Split anything long into labeled units, so a question can return a location. The interface is working code; the understanding layer is concept aliasing and keyword scoring. A production version would swap in embeddings; the interaction wouldn’t change.

Decisions

01

The answer is a timestamp, not text

“Search as navigation.”

The query relocates you to the moment where the answer lives. No summaries, no transcripts.

02

Segments, not a search results list

“The timeline is the interface.”

Labeled semantic segments; relevant ones highlight. You see the shape of the answer before you click.

03

The query stays visible while you watch

“Context persists.”

The panel stays open beside the video, so follow-ups never cost you your place.

What I’d Change

Confidence indicators. The timeline should visually encode match confidence so the user can prioritize where to jump.

Multi-video support. The real value is cross-video search: “find the part about heat shields” across an entire lecture series.
