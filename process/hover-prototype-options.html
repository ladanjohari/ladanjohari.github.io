Designed hover prototypes

Same recipe as the Session Indicator hover: not footage, a choreographed prototype. Zoomed into the one feature that defines the project, one small interaction, then reset, looping seamlessly. Big frame is 2× for judging detail; below it, the real 196×122 context in the row. Two directions per project: one cursor-driven (someone using it) and one ambient (the system doing its thing).
